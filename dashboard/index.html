Mini Tunnel
Public ứng dụng local qua Cloudflare Worker
Không liên lạc được với client local. Hãy chắc chắn cửa sổ chạy npm start vẫn đang mở — trang sẽ tự kết nối lại.

Bắt đầu trong 2 bước

Mini Tunnel cần một Cloudflare Worker (miễn phí) làm địa chỉ public. Máy bạn chỉ cần kết nối ra ngoài — không mở port, không cần IP tĩnh.

  1. 1
    Tạo Worker trên Cloudflare

    Mở một cửa sổ terminal mới trong thư mục dự án và chạy lệnh dưới. Lệnh sẽ mở trình duyệt để đăng nhập Cloudflare, deploy Worker, tạo token và tự điền vào đây.

    npm run setup

    Đã có Worker? Nhập Worker URL và token thủ công.

  2. 2
    Thêm tunnel

    Chọn cổng của ứng dụng đang chạy trên máy (ví dụ 8001) — bạn sẽ nhận được một địa chỉ https:// để gửi cho người khác.

    Kết nối Cloudflare Worker

    Chưa có Worker? Chạy npm run setup trong thư mục dự án — lệnh này tự điền 2 ô dưới đây.

    Phải trùng với secret TUNNEL_TOKEN của Worker. Token không bao giờ được hiển thị lại trên dashboard.
